# Davis OS v1.97 — Pebble
Pebble is a native Ring-3 micro-friction ledger. It captures a small recurring annoyance, its context, estimated minutes lost, and a proposed way to remove the friction. The right panel accumulates recorded friction debt and entry count from an append-only local log at `/Home/Documents/PEBBLE.LOG`.

The design intentionally differs from task managers and conventional time trackers: its primary object is not a task or activity interval, but a discrete friction event that is normally too small to record. Repeated entries make cumulative operational drag visible so the user can decide which annoyance is worth eliminating or automating.

Prior-art search (September 2026) found general time trackers, time-debt tools, productivity systems, and discussion of micro-friction, but no obvious widely deployed desktop application over the last decade centered specifically on an append-only micro-friction event ledger with cumulative estimated loss and remediation notes. This is a practical search result, not a patentability or exhaustive nonexistence claim.
