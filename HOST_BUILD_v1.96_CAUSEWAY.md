# Davis OS v1.96 — Causeway
Causeway is a native Ring-3 "why-ledger" for changes. Each append-only capsule keeps intent, expected outcome, observed outcome, and recovery knowledge together. It persists to `/Home/Documents/CAUSEWAY.LOG`, uses only window/IPC/file capabilities, is loaded by UEFI as a known DXE application, and appears in Applications.

Prior-art review found abundant audit trails, configuration/change management, provenance research, and 2026 agent-code provenance tools, but no obvious widely deployed consumer desktop application whose primary unit is an append-only intent→expectation→observation→recovery capsule spanning arbitrary system changes. This is a practical novelty claim, not a patentability or exhaustive nonexistence claim.
