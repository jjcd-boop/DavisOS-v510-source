# Davis OS v3.10 — Forge Private Service Foundation

This revision begins implementing the Davis-side services required by the consolidated Forge 3 architecture.

## Brokered private application state
- Added kernel syscalls `ForgeStoreRead` (55) and `ForgeStoreWrite` (56).
- Access is restricted to the SystemService security domain and still requires IPC capability.
- ForgeRunner remains Window + IPC only (DXE2 caps 0x11); it receives no general File Read/Write capability.
- The broker derives a private `/System/ForgeStore/<program-hash>` namespace and never accepts a caller-supplied filesystem path.
- FBC3 has no raw syscall primitive, so generated bytecode cannot invoke the broker directly or choose another filesystem path.
- ForgeRunner serializes bounded counter/variable/condition/list state and restores it when the same named generated application is relaunched.

## Persistence boundary
The current Davis `DxeServices` file store is RAM-backed. Therefore v3.10 state survives generated-app process restarts during the same Davis boot, but does NOT yet survive a reboot. Durable reboot persistence still requires the physical storage/filesystem service to back this broker.

## Security
- Forge app: Window + IPC + File Read/Write (0x17), for authoring artifacts.
- ForgeRunner: Window + IPC (0x11).
- Generated FBC3: interpreted and independently validated.
- No Driver I/O, DMA, IRQ, or raw PCI authority was added.
