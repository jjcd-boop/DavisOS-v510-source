# Davis OS v1.94 — Visual Refinement

This pass is intentionally presentation-focused. It preserves the v1.93 hardware recovery work while refining the desktop shell.

- Calmer Davis Classic palette with higher text/panel contrast.
- Softer layered landscape and less blocky horizon.
- Slim accent rules on header/taskbar instead of heavy framing.
- Desktop launchers use consistent cards, shadows, radii, and icon geometry.
- Taskbar buttons use a quieter panel treatment and `DAVIS` Start label.
- System rail now reads as a floating side panel with a single accent spine.
- Managed windows use subtle shadows, neutral title bars, and a thin accent rule.
- Shell errors/status messages are now toast-style notices rather than plain rectangles.
- Existing hit targets and application/hardware logic were deliberately preserved.
