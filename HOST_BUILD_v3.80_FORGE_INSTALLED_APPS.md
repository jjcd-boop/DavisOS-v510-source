# Davis OS v3.80 — Forge Installed Application Foundation

This consolidated pass adds a kernel-mediated installed Forge package registry rather than treating .fpkg as a loose artifact only.

- Up to 12 installed FDL3/FBC3 packages.
- Packages contain bounded bytecode, budget, requested caps, stable app key, name, and integrity digest.
- Registry validates packages again in Ring 0 before accepting them.
- Registry entries use the existing UEFI-backed ForgePersistentStore when firmware runtime variables are available.
- Reinstalling the same app key upgrades that slot instead of consuming another slot.
- New package syscalls are IPC-capability gated and application-domain restricted.
- Generated bytecode receives no package-management syscall primitive.
- Forge automatically installs a package only after FBC3 compile, sandbox validation, live Ring-3 acknowledgement, and package emission succeed.

The registry is a permanent-app foundation; desktop dynamic enumeration/launch UI remains a later integration point. Hardware validation of UEFI persistence remains required.
