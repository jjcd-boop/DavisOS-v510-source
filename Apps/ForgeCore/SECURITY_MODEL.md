# Forge 3 security model
Forge is an Application-domain authoring tool. Each live generated program is promoted by cloning the trusted ForgeRunner template into a fresh CPL3 process/address space. ForgeRunner receives Window+IPC only. Generated bytecode is data, never native executable memory.
Raw PCI, driver I/O, IRQ and DMA are prohibited. Persistent storage/network access must be mediated by dedicated brokers with per-application namespaces/policy before FDL3 can expose those facilities.
