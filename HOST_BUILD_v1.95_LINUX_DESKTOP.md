# Davis OS v1.95 — Linux Desktop Visual Pass

Visual-only refinement based on v1.94/v1.93 hardware recovery.

- Reworked default desktop toward a familiar Linux desktop aesthetic (XFCE/Cinnamon-inspired rather than cloning a distribution).
- Dark neutral top panel with Applications, Places, System, and workspace indicator.
- Dark bottom window panel with Menu and application task buttons.
- Neutral blue/graphite wallpaper replacing the stylized landscape.
- Flatter, tighter controls and window chrome with green Davis accent.
- Start menu terminology updated toward Linux desktop conventions.
- Existing click/hit geometry preserved so the visual pass does not disturb hardware recovery testing.
- No Linux runtime, ABI, kernel, syscall, driver, or filesystem dependency was introduced. Davis OS remains its own operating system.
